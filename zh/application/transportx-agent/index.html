产品简介

Codex、Claude Code 等编程 Agent 进步很快，但实际使用通常仍离不开代码、终端和文件结构。对于需要分析交通数据、制作地图，却没有编程背景的业务人员，这仍是一道明显门槛。

TransportX 的出发点很简单：让交通分析人员能直接使用 Agent 完成提问、分析、制图和成果交付，并保留结果所依据的数据与过程。平台本身保持轻量，具体数据、知识、方法和工具通过 Module 装配，因此也可以适配交通之外的数据分析场景。

可以协助的工作

对话式分析
用自然语言提出问题，查看模型回复、工具调用和生成文件。
交互式 GIS
Agent 与分析人员共享带版本的地图上下文，并通过图层、要素、点位、矩形和视野完成空间交互。
数据、图表与视频
分析表格、数据库和代码，生成图表；通过 Video Capability 增加视频检索、播放、裁剪、抽帧和时序指标。
可核查结论
让引用、地图上下文、源文件和工具输出与使用它们的结论保持关联。
报告交付
生成包含图件和引用的 Markdown 报告，并在桌面端导出 PDF。
版本化能力
通过版本化 Module 安装 Agent Skill、Extension、Data、Knowledge、Template 和本地运行时。

工作流程

  1. 创建交通任务

    选择分析所需的模型与版本化 Module。

  2. 提出问题

    使用自然语言展开分析，同时保留模型回复、工具调用和生成文件。

  3. 在共享地图中分析

    查看图层，并把要素、点位、矩形或当前视野作为 Geo Context 交给 Agent。

  4. 交付报告

    核查结论、图件、引用和源文件，并将报告导出为 PDF。
