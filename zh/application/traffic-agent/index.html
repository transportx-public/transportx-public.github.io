Traffic Agent

一个面向交通分析任务的研究原型，将交通问数、地图交互、知识检索与报告整理放在同一个对话式工作台中。

产品简介

Traffic Agent 是一个面向交通分析任务的研究原型。它把交通问数、地图交互、知识检索和报告整理放进同一个对话式工作台。用户可以从一个具体的交通问题出发，查看相关数据和空间证据，并在多轮任务中保留中间结果。

Agent 会根据问题选择数据查询、空间分析、检索和可视化工具。输出主要用于辅助分析与复核，不替代交通专业判断。

工作流程

  1. 任务规划

    明确问题、所需证据与预期输出。

  2. 数据问数

    选择相关数据，在分析前核对口径与字段。

  3. 地图交互

    执行空间分析，并在交互地图上查看结果。

  4. 知识检索

    在任务需要背景材料时检索相关内容。

  5. 分析报告

    整理结论、来源和中间结果，便于复核。

可以协助的工作

交通问数
将自然语言问题连接到相关交通数据与查询工具。
空间分析
在地图上查看站点、线路、缓冲区等空间关系。
知识与报告
结合检索材料和分析结果，整理简明报告。
