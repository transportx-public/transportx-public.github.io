Short-term passenger flow forecast for urban rail transit based on multi-source data

利用物联网采集的多源客流数据，提出一种SARIMA + SVM 的组合模型，用于城市轨道交通短期客流预测，并在北京地铁真实数据上验证其有效性。

TrafficSimAgent: A Hierarchical Agent Framework for Autonomous Traffic Simulation with MCP Control

针对现有交通仿真平台需专业知识、缺乏自动优化等问题，提出基于 LLM 的多智能体框架 TrafficSimAgent。通过抽象 API、任务理解规划及嵌入式优化模块，实现自然语言指令驱动的自主仿真与优化，在多场景下表现出优异的通用性和性能。

@卢永晟arXiv 2025-12暂无

Geo-Llama: Leveraging LLMs for Human Mobility Trajectory Generation with Constraints

本研究针对现有移动生成模型缺乏可控性的问题，提出了Geo-Llama框架。该框架利用大语言模型（LLM）并通过一种新颖的“访问打乱（Visit-wise Permutation）”策略进行微调，不仅能生成逼真的轨迹，还能强制执行特定的时空访问约束（如必须在特定时间到达特定地点），同时保持轨迹的上下文连贯性。
